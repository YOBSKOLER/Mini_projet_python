# Mini Python Project

This repository contains several small Python mini-projects designed to practice the basics of the language: user input, conditions, loops, lists, functions, and simple game logic.

## Project contents

- `mystere.py` : number guessing game
- `liste.py` : shopping list manager
- `jeu_de_role.py` : text-based role-playing battle game
- `cal.py` : simple calculator for two numbers

## File descriptions

### 1) `mystere.py`

A game where the user must guess a random number between 1 and 100.

Features:

- random generation of the mystery number
- display of remaining attempts
- messages like "higher" and "lower"
- end of the game after 6 attempts

Run the program

```bash
python mystere.py
```

### 2) `liste.py`

A small program to manage a shopping list.

Features

- add an item
- remove an item
- display the list
- exit the program

Run the program

```bash
python liste.py
```

### 3) `jeu_de_role.py`

A text-based mini combat game.

Features

- player attack
- healing potion
- defense that reduces incoming damage
- random damage and critical hits
- enemy AI behavior

Run the program

```bash
python jeu_de_role.py
```

### 4) `cal.py`

A simple calculator that adds two numbers entered by the user.

Features

- input of two numbers
- conversion to `int`
- error handling when the user enters a non-numeric value

Run the program

```bash
python cal.py
```

## Prerequisites

- Python 3 installed on your system
- a terminal or command prompt

Check the Python version:

```bash
python --version
```

## Mini Projet Python

Ce dépôt contient plusieurs mini-projets Python simples conçus pour pratiquer les bases du langage : saisie utilisateur, conditions, boucles, listes, fonctions et logique de jeu.

## Contenu du projet

- `mystere.py` : jeu du nombre mystère
- `liste.py` : gestion d'une liste de courses
- `jeu_de_role.py` : mini jeu de rôle au tour par tour
- `cal.py` : calculatrice simple de deux nombres

## Description des fichiers

### 1)  `mystere.py`

Jeu où l'utilisateur doit deviner un nombre aléatoire entre 1 et 100.

Fonctionnalités :

- génération aléatoire du nombre mystère
- affichage du nombre d'essais restants
- messages « plus grand » / « plus petit »
- fin de partie après 6 essais

Pour lancer le programme :

```bash
python mystere.py
```

### 2)  `liste.py`

Petit programme pour gérer une liste de courses.

Fonctionnalités :

- ajouter un élément
- retirer un élément
- afficher la liste
- quitter le programme

Pour lancer le programme :

```bash
python liste.py
```

### 3)  `jeu_de_role.py`

Mini jeu de combat en mode texte.

Fonctionnalités :

- attaque du joueur
- potion de soin
- défense réduisant les dégâts
- dégâts aléatoires et coups critiques
- intelligence artificielle de l'ennemi

Pour lancer le programme :

```bash
python jeu_de_role.py
```

### 4)  `cal.py`

Calculatrice simple qui additionne deux nombres saisis par l'utilisateur.

Fonctionnalités :

- saisie de deux nombres
- conversion en `int`
- gestion des erreurs si l'utilisateur entre autre chose qu'un nombre

Pour lancer le programme :

```bash
python cal.py
```
